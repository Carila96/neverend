# neverEND Audience-first Growth Strategy

最終更新: 2026-09-15

## 現在の位置づけ

neverENDはすでに公開中のブラウザゲームである。

収益モデルとして「ゲーム内の背景・空間を購入し、ブランドや個人が広告/スポンサー表示に使える」仕組みを持つが、現段階では広告商品を前面に押し出さない。

優先順位は次の通り。

1. ゲーム自体が遊ばれる
2. 見た人が他人へ見せたくなる
3. ゲームの場所そのものに注目が集まる
4. 既存スポンサー/購入例が見える
5. その注目を背景・広告枠の価値へ転換する

「広告枠を売るために人を集める」のではなく、「人が集まった場所に広告価値が生まれる」順序を守る。

## The Million Dollar Homepageから採用する原則

参考にするのは表面の「場所を小分けにして売る」だけではない。

重要なのは次の構造。

- 最初の購入例を身近な人から作り、空の売り場を避ける。
- 小さな売上/参加実績を作ってから、物語としてメディアへ持ち込む。
- 商品そのものより「なぜこんなことをしているのか」という話題性を広げる。
- 注目が増えるほど残り枠の価値が上がる構造を作る。
- 既存購入者が見えることで次の購入者の心理的障壁を下げる。

neverENDでは「大学費用を作る100万ピクセル」の物語をコピーしない。
ゲーム固有の物語を作る。

## neverENDの表向きメッセージ

第一メッセージはゲーム。

現在の軸:
- 30秒
- 死ぬ
- リセット
- もう一度
- どこまで登れるか

広告・背景購入は、初見プレイヤー向けのOGPや主要動画タイトルの中心に置かない。

スポンサー販売を前に出すのは、少なくとも次のどれかが成立してから。
- 継続的なプレイ流入
- 共有/動画での反応
- 実在する最初の背景スポンサー
- 閲覧数を広告主へ示せる状態

## Growthの3経路

### Push

- YouTube / Shortsで実プレイの失敗・惜しい瞬間・記録更新を見せる
- X等で短いプレイクリップを出す
- rage game / hard platformerを扱う配信者へ個別に紹介する
- 「広告を買ってください」ではなく「このゲーム、どこまで行ける？」で届ける

### Pull

- browser game / hard platformer / rage game等の検索導線
- ゲーム発見プラットフォームへの掲載
- SEO metadata / OGP / titleをゲームとして強くする
- 検索結果や掲載面から即プレイできる状態を維持

### Loop

- スコア/到達階の共有
- 「あと少しだった」瞬間を共有しやすくする
- leaderboard / recordの競争性
- 配信・動画で見た人が自分でも試せる短いURL
- 将来スポンサー背景自体が話題になる仕組み

## スポンサー導入の段階

### Phase 1 — Audience

ゲームの面白さ・難しさ・競争性を先に育てる。
販売ページへの導線は存在してよいが、主メッセージにはしない。

### Phase 2 — Seed Social Proof

最初の1〜数枠を実際に埋める。
候補は、プロジェクト関係者、自社ブランド、協力者等。
無料・割引・通常購入のどれにするかは都度人間が判断する。

目的は売上額だけでなく、
「ここに実際に何かが載る」ことをプレイヤーと次のスポンサーへ見せること。

### Phase 3 — Story / Press

次のような実績ができた時点で外部発信を強める。

- プレイ回数
- ユニークユーザー
- 最高到達/死亡数等のゲーム固有データ
- 最初のスポンサー
- 背景が実際に買われた事実
- SNS/動画での反応

売り文句は「広告枠あります」ではなく、
「遊ばれているゲームの世界の一部を買える」という物語へする。

### Phase 4 — Sponsor Sales

広告主へ提示するのは単価だけではなく、
- 実閲覧
- ゲーム内での露出位置
- 表示期間
- 既存スポンサー例
- プレイヤー層
- 話題性/共有性

をまとめる。

## キャッチコピー / OGP方針

現段階ではゲームファーストを維持する。

候補:
- 30 Seconds. One Tower. How High Can You Get?
- You Have 30 Seconds. The Tower Doesn't Care.
- Die. Reset. Climb Higher.

広告モデルの説明はsales pageと将来のpress/storyページに分離する。

## 計測

既存Growth funnel:
- app_view
- sales_view
- sales_cta
- checkout_created
- purchase_completed

Audience段階ではsales conversionだけを追わず、
- app view
- repeat play
- score/record
- share
- video/social referral
を優先して観測する。

## 次の優先課題

1. 現在のゲーム流入を把握する。
2. 共有されるプレイ結果/瞬間を強くする。
3. Push / Pullのうち最低1つずつ実運用を開始する。
4. 最初の背景掲載例を作るタイミングを判断する。
5. 実績ができてからスポンサー向け売り文句を強化する。
